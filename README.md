## What this is

Truth Code XYZ is a complete spiritual framework in three chapters:

- **Spiritual Science** — the laws by which the spirit lives.
- **Spiritual Mathematics** — the equation by which life is built.
- **Divine Love** — the polarity in relationships through which the soul is refined.

Each chapter stands on its own. Read them in any order. Together they are one teaching.

The framework belongs to no tradition exclusively. It was birthed during long bouts of stillness and reflection. It draws on biblical wisdom and Akan spiritual heritage (the Okra, the Sunsum, the currents of masculine and feminine), and it mirrors many teachings and philosophies across the planet, simply because the truth is everywhere.

Open `index.html` in any modern browser. The site is fully self-contained — every font, image, and stylesheet is embedded. No internet connection or hosting required.
